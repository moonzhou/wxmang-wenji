## 这个仓库是什么

- 一个**可独立 clone / fork / 镜像**的文章存档，不依赖本项目的站点即可阅读。
- 每篇正文开头保留**原始署名、首发日期与原文链接**，可逐篇回溯源站。
- 同一篇文章若在多个论坛批次里重复出现，**合并为一篇**，并在 `_meta/SOURCES.csv`
  中保留全部原始链接。

### 这个仓库不是什么

- 不是 wxmang.site 的完整镜像。该站收录了 **380 余位作者**、1421 条内容，
  本仓库只收**真实署名 wxmang** 的部分。其余作者的作品不在收录范围。
- 不是授权版本。见下节《版权与下架》。

```

├── LICENSE                许可与版权声明（请先读这一份）
├── README.md
├── _meta/                 元数据与整理记录（下划线开头，站点构建时自动忽略）

├── _tools/                抓取与整理脚本（同上，不参与站点构建）
│   ├── fetch_meta.py      抓原始页面的真实元数据
│   ├── wxlib.py           公共解析与去重逻辑
│   ├── build_corpus.py    生成权威文集口径
│   ├── scaffold.py        生成各级 _index.md 骨架
│   └── fetch_articles.py  抓正文并渲染为 Markdown
├── _index.md              文集总入口
├── 01-管理学/ … 09-其他/    九个大类
│   ├── _index.md
│   └── <系列名>/           系列自成一个目录（≥3 篇才单列）
└── about/index.md         整理原则与版权说明（站点页面）
```

## 版权与下架

- **原文著作权归 wxmang 所有。** 本仓库仅作非商业的整理、存档与阅读便利之用。
- 本项目对**整理成果**（索引、分类、去重、校对、目录结构）以
  **CC BY-NC-SA 4.0** 释出。该许可不适用于文章原文。
- 每篇文章均保留原始署名与原文链接，未做实质性删改；仅剔除原页面附带的论坛元数据
  （标签、送花/推宝记录、留言计数）与网友留言区。
- **下架通道**：原作者或权利人如不希望某篇（或全部）内容被收录，
  请通过 <https://zmsite.top/about/> 上的联系方式告知，我们承诺在 **48 小时内**撤下，
  且不需要说明理由。撤下单篇只删除一个文件，不影响其他页面。
